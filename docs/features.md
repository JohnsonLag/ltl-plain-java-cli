## Features

### Create

* Create entries by inputting a file with URLs.

### Read

* Read an individual entry on the command line by using the entry number.

* Read many entry overviews by using the keyword “many”.

* Read the search result overviews by by using the keyword “results”.

### Update

* Update an individual entry on the command line by using the entry number. Allows you to edit the entry URL, title, and notes.

  - Entry notes have a limit of 2047 characters.

### Delete

* Delete an individual entry on the command line by using the entry number.

### Search

* Search the library by enclosing your search string in quotation marks.
