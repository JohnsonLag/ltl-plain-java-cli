# Local Text Library (ltl)

Local text library project, built in Java, made to run on the command-line.

This program lets you save text from web pages online to your local computer, allowing you to read, search, and take notes offline.

See the [setup guide](./docs/general-setup.md) and [troubleshooting guide](./docs/general-troubleshooting.md) for instructions on how to install and run the program.
